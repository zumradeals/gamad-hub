# Web App

Frontend Next.js du GAMAD HUB CORE.

Cette phase applique une fondation visuelle sobre et institutionnelle au CORE existant.

## UI Foundation

- Palette GAMAD centralisee dans `packages/design-tokens`.
- Variables CSS exposees dans `app/globals.css`.
- Sidebar Deep Navy stable.
- Accents Gold, Earth Blue et Earth Green reserves aux actions, statuts et hierarchies.
- Cartes, tables, badges, boutons et formulaires harmonises.
- Le frontend ne porte aucune logique de permission reelle.
