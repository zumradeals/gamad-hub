## Doctrine

- Public, discret, institutionnel et mobile-first.
- Aucun detail souverain du CORE n'est expose.
- Aucun mecanisme de permission, audit ou gouvernance n'est porte par le frontend public.
- La route `/connexion` reste un acces membre sobre vers le HUB CORE.
