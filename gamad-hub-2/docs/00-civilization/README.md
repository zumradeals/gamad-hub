# 00-civilization — Les lois du monde GAMAD

Ce dossier contient les documents fondateurs invariants du système GAMAD.
Ils définissent CE QUE GAMAD EST, pas comment il fonctionne techniquement.

Ces documents ne changent pas avec les itérations techniques.
Toute décision d'architecture ou d'implémentation doit rester cohérente avec eux.
En cas de contradiction entre un document technique et un document de cette couche,
la doctrine de cette couche prime.
