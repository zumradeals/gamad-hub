# Documentation GAMAD HUB CORE

Cette documentation Markdown est la source de verite du projet GAMAD HUB CORE.

Le MVP couvre :

- Identity Core
- Permission Engine
- Organization Core
- Audit & Event Engine
- Knowledge Core
- Activity Core
- Communication minimale
- Frontend MVP
- Docker/VPS foundation

Exclus du MVP :

- Wallet
- Marketplace
- TV / streaming
- IA avancee
- Blockchain
- Reseau social massif
- Gamification massive
