# 00-foundation — Les modèles civils de GAMAD

Ce dossier contient les modèles qui décrivent comment GAMAD s'organise
en tant que civilisation numérique : citoyenneté, visibilité, niveaux
d'appartenance, relation entre le public et le souverain.

Ces documents sont distincts de 00-civilization :
- 00-civilization définit les LOIS (invariants absolus)
- 00-foundation définit les MODÈLES (comment ces lois s'appliquent aux humains)
