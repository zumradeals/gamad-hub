# GAMAD CORE — Doctrine de l'Identite

## Nature du document

Ce document definit la nature de l'identite dans le monde GAMAD.

Le GAMAD ID ne constitue pas uniquement un compte technique.

Il represente l'existence reconnue dans le monde numerique GAMAD.

---

# Principe fondamental

Toute entite reconnue dans le Core possede une identite.

Cette identite peut appartenir :

- a un humain ;
- une organisation ;
- une IA ;
- un systeme ;
- une institution ;
- un satellite.

---

# Nature du GAMAD ID

Le GAMAD ID constitue :

- une existence ;
- une appartenance ;
- une reputation ;
- une responsabilite ;
- une couche de confiance ;
- une memoire historisable.

---

# Proprietes fondamentales

## 1. Persistence

Une identite reconnue ne disparait pas arbitrairement.

---

## 2. Historicite

Toute identite possede :

- un historique ;
- des actions ;
- des relations ;
- des traces.

---

## 3. Responsabilite

Toute action critique doit etre attribuable a une identite.

---

## 4. Reputation

Le Core peut associer :

- confiance ;
- historique ;
- contributions ;
- validations ;
- restrictions.

---

## 5. Appartenance

Une identite peut appartenir :

- a un Zumara ;
- une institution ;
- une organisation ;
- une mission ;
- une structure.

---

Memoire temporelle.

---

# Regles fondamentales

## 1. Aucune action critique anonyme.

## 2. Toute permission doit etre explicite.

## 3. Toute identite critique doit etre auditée.

## 4. L'identite appartient au Core.

## 5. Aucun satellite ne doit redefinir l'identite souveraine.

---

# Finalite

Le GAMAD ID constitue le tissu existentiel du monde GAMAD.

Il relie :

- les humains ;
- les institutions ;
- les services ;
- les organisations ;
- les satellites ;
- les intelligences artificielles.
