# Doctrine des Zumara

## Definition

Les Zumara constituent des cellules organiques d'action, de transmission et d'evolution dans le monde GAMAD.

Le monde GAMAD n'evolue pas uniquement par une administration centrale.

Il evolue aussi par des cellules autonomes capables d'innover, transmettre, produire et proteger.

---

## Nature

Un Zumara peut etre :

- technique ;
- scientifique ;
- educatif ;
- mediatique ;
- economique ;
- culturel ;
- securitaire ;
- humanitaire.

---

## Capacites

Un Zumara peut :

- produire des technologies ;
- publier ;
- enseigner ;
- former ;
- experimenter ;
- proteger des infrastructures ;
- creer des services satellites.

---

## Relation avec le Core

Le Core garantit :

- l'identite ;
- les permissions ;
- les contrats ;
- la coherence ;
- la tracabilite.

Les Zumara garantissent :

- l'evolution ;
- l'innovation ;
- l'expansion ;
- la transmission.

---

## Regles fondamentales

1. Tout Zumara possede une identite.

2. Toute action critique doit etre tracable.

3. Aucun Zumara ne peut contourner les lois souveraines du Core.

4. Les Zumara peuvent creer des structures specialisees.

5. Les Zumara peuvent evoluer sans compromettre la coherence du monde GAMAD.

---

## Finalite

Les Zumara constituent le moteur organique d'evolution civilisationnelle du monde GAMAD.
