# GAMAD CORE — Ontologie du Monde Numerique

## Nature du document

Ce document definit ce qui peut exister dans le monde GAMAD.

L'ontologie constitue la couche de coherence fondamentale du Core.

Chaque element reconnu dans le systeme doit appartenir a une categorie existentielle clairement definie.

---

# Principe fondamental

Le Core ne gere pas uniquement des utilisateurs.

Le Core gere des entites.

Chaque entite possede :

- une identite ;
- un type ;
- un historique ;
- des permissions ;
- des relations ;
- une responsabilite ;
- une existence historisable.

---

# Categories fondamentales d'entites

## 1. Humain

Entite biologique reconnue dans le monde GAMAD.

Exemples :

- utilisateur ;
- citoyen ;
- redacteur ;
- administrateur ;
- contributeur ;
- superviseur.

---

## 2. Organisation

Structure collective reconnue.

Exemples :

- entreprise ;
- association ;
- institution ;
- cellule ;
- groupe ;
- ecosysteme partenaire.

---

## 3. Zumara

Cellule de transmission et d'action.

Le Zumara constitue une unite organique du monde GAMAD.

Un Zumara peut :

- produire ;
- enseigner ;
- gouverner ;
- proteger ;
- innover ;
- financer ;
- transmettre.

---

## 4. Institution

Organe officiel possedant une responsabilite structurelle.

Exemples :

- gouvernance ;
- audit ;
- moderation ;
- validation ;
- justice ;
- regulation.

---

## 5. Satellite

Service connecte au Core via des contrats.

Le satellite ne constitue pas le monde lui-meme.

Il opere dans le monde.

Exemples :

- GAMAD TV ;
- GAMAD Blog ;
- GAMAD Mail ;
- GAMAD Cloud.

---

## 6. Systeme

Composant technique autonome.

Exemples :

- backend ;
- API ;
- moteur de recherche ;
- moteur d'evenements ;
- systeme de permissions.

---

## 7. Intelligence artificielle

Entite non biologique reconnue par le Core.

Une IA peut recevoir :

- une identite ;
- des permissions ;
- des restrictions ;
- des responsabilites.

---

## 8. Ressource

Objet informationnel historisable.

Exemples :

- document ;
- article ;
- video ;
- archive ;
- preuve ;
- rapport.

---

## 9. Contrat

Structure definissant une relation ou une regle officielle.

Les contrats constituent le langage souverain du Core.

---

# Relations fondamentales

Les entites peuvent :

- appartenir ;
- superviser ;
- collaborer ;
- valider ;
- publier ;
- transmettre ;
- proteger ;
- gouverner ;
- auditer.

---

# Regles ontologiques

## 1. Toute entite possede une identite.

## 2. Toute entite importante possede un historique.

## 3. Toute relation importante doit etre tracable.

## 4. Aucune permission critique implicite.

## 5. Toute entite critique peut etre auditée.

---

# Finalite

L'ontologie permet :

- la coherence du monde ;
- la stabilite des permissions ;
- la gouvernance ;
- la transmissibilite ;
- l'evolution civilisationnelle du Core.
