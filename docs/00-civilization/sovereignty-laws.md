# GAMAD CORE — Lois de Souverainete

## Nature du document

Ce document definit les zones de souverainete absolue du Core.

Le Core constitue l'autorite fondamentale du monde GAMAD.

Les satellites, services et extensions peuvent evoluer librement tant qu'ils ne compromettent pas les lois souveraines.

---

# Principe fondamental

Tout n'appartient pas au Core.

Mais certaines fonctions ne doivent jamais quitter le Core.

---

# Zones souveraines

## 1. Identite

Le Core controle :

- le GAMAD ID ;
- les relations identitaires ;
- les permissions fondamentales ;
- les statuts d'existence.

---

## 2. Permissions

Aucun satellite ne constitue une autorite souveraine.

Les permissions critiques proviennent du Core.

---

## 3. Historique

Le Core porte :

- les audits ;
- les preuves ;
- les evenements ;
- les traces historiques.

---

## 4. Contrats

Les contrats definissent les relations officielles.

Aucun satellite ne peut redefinir unilateralement les contrats souverains.

---

## 5. Gouvernance

Le Core garantit :

- coherence ;
- stabilite ;
- continuite ;
- gouvernabilite.

---

# Frontieres

## Ce qui appartient au Core

- identite ;
- permissions ;
- contrats ;
- audit ;
- memoire ;
- gouvernance.

---

## Ce qui peut rester externe

- interfaces ;
- frontends ;
- experiences utilisateur ;
- medias ;
- outils specialises ;
- satellites independants.

---

# Regles fondamentales

## 1. Aucun satellite ne doit contourner le Core.

## 2. Toute action critique doit etre historisee.

## 3. Toute permission critique doit etre verifiable.

## 4. Le systeme doit survivre a la chute des satellites.

## 5. Les contrats priment sur les implementations.

---

# Finalite

La souverainete du Core garantit :

- la coherence du monde ;
- la stabilite civilisationnelle ;
- la reconstructibilite ;
- la continuite historique ;
- la survie du systeme au-dela des technologies temporaires.
